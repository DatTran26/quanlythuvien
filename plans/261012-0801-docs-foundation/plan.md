# Tài liệu nền tảng dự án

## Outcome

Tạo README gốc và bộ tài liệu kỹ thuật dễ điều hướng, có hướng dẫn cài đặt cục bộ, kiến trúc và quy ước phát triển; không thay thế tài liệu nghiệp vụ theo feature.

## Scope

- README gốc và navigation tại `docs/README.md`.
- Preset tài liệu: tổng quan sản phẩm, chuẩn mã, điều hướng mã, hướng dẫn thiết kế, cài đặt/vận hành, kiến trúc và roadmap.
- Liên kết tới owner thực thi hoặc tài liệu nghiệp vụ hiện có thay vì sao chép hợp đồng.

## Validation

- Các đường dẫn Markdown nội bộ phải tồn tại.
- Command cài đặt và kiểm thử phải khớp manifest/cấu hình hiện có.
- Không đưa bí mật, đường dẫn vận hành production chưa kiểm chứng hoặc dữ liệu sao lưu vào tài liệu.
